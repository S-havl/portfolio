## Executive Summary
I started out scripting game mechanics in Lua and evolved into low-level systems architecture and memory management. My focus lies in Operating System Development (OSDev), binary reverse engineering, and security research. I prioritize clean C code, dependency-free architectures, and absolute control over the hardware.

## Featured Engineering

<div class="project-card">
  <h3><a href="https://github.com/tu-usuario/strix">Strix OS</a></h3>
  <p>A custom 64-bit operating system kernel written from scratch in C and x86_64 Assembly.</p>
  <ul>
    <li><b>Architecture:</b> Bare-metal initialization and custom bootloader design.</li>
    <li><b>Implementation:</b> Memory map retrieval via BIOS interrupts (e820) and VBE graphics mode configuration.</li>
