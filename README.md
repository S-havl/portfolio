## ⚙️ Featured Engineering

### [Strix OS](https://github.com/tu-usuario/strix)
*A custom 64-bit operating system kernel written from scratch in C and x86_64 Assembly.*
* **Architecture:** Bare-metal initialization and custom bootloader design.
* **Implementation:** Memory map retrieval via BIOS interrupts (e820) and VBE graphics mode configuration.
* **Infrastructure:** Built using an isolated GCC toolchain and emulated on QEMU via Docker containers.

<br>

### [Mirage](https://github.com/tu-usuario/mirage)
*A modular C utility for text transformation and hidden character processing.*
* **Architecture:** Robust state machine design for efficient data parsing.
* **Build System:** Cross-platform, multi-file compilation management via custom Makefiles.
